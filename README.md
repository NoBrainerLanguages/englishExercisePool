# EnglishExercisePool
Pool de exercícios interativos de inglês para estudantes brasileiros.
Exercícios interativos criados em ambiente Web simples, front-end estático, HTML, CSS e JavaScript (e eventuais frameworks que melhor atenderem às necessidades de desenvolvimento responsivo e seguro)
Código web aberto, criado por iniciativa da marca registrada NoBrainer Languages. Aprenda inglês com nossos vídeos no YouTube https://nobrainerlanguages.com/@NoBrainerLanguages
